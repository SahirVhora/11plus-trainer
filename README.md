# 11+ Trainer

[![Live site](https://img.shields.io/badge/Live_site-11%2B_Trainer-5b4fc4?style=flat-square)](https://sahirvhora.github.io/11plus-trainer/)

Free 11+ practice for UK grammar school entry. The self-contained browser app includes visual non-verbal reasoning, vocabulary revision, maths and verbal reasoning questions, plus timed GL-style mock exams.

## Features

- Procedurally generated visual NVR questions
- Vocabulary practice with on-device progress
- Unlimited maths and verbal reasoning practice
- Timed mock exams
- No accounts, ads or external data collection

## Run locally

Open `index.html` in any modern browser. No build step or server is required.

## Privacy

Progress is stored only in the browser using localStorage. The app does not send practice data to a server.
